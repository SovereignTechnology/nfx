# Pre-push review — A2 `nfx-media` (`a2/nfx-media`, 2026-09-23)

Scope:
- `crates/nfx-media` (probe, ladder, argv, storyboard, mp4, package, the `nfx-package`
  CLI, tests);
- the `check.sh` ffmpeg step;
- the NFX-05 §1 clarification and the status file.

Method: `differential-review` (a new crate that spawns processes and parses untrusted
media metadata) and `sharp-edges`.

## Attack surface and dispositions

| Surface | Risk | Disposition |
|---|---|---|
| Spawning ffmpeg/ffprobe | shell injection | Argv vectors only (`Command::args`), never a shell. The L8 injection tests are ported: a hostile filename stays one element in every builder. The integration test packages a file named `source $(id) 'x'.mp4`. |
| Input names reaching ffmpeg | ffmpeg interprets protocol prefixes (`concat:`, `http:`, `subfile,,…`), so a crafted "path" can read other resources | **Hardened:** the input is canonicalised, must be a regular file, and is passed as `file:<absolute path>`. |
| `-hls_segment_filename` | ffmpeg expands `%` as a format string | An output directory containing `%` is rejected. The work dir is canonicalised. |
| ffmpeg's playlist output | a manipulated playlist could name files outside the work dir | Segment lines must be plain names (`[A-Za-z0-9_.-]`, no leading dot, no `/`). `EXT-X-MAP` must be exactly `init.mp4`. The playlist must be complete (`#EXT-X-ENDLIST`). |
| Store writes | path traversal, torn files | Names are sha256 hex computed locally. Writes go to a temp file and are renamed; an existing file is reused only if it re-verifies. |
| ISO-BMFF parsing | out-of-bounds reads on malformed init segments | Every read goes through checked `get`. A test feeds every truncation of a valid init and asserts no panic. Oversized, undersized and lying box sizes are errors. |
| Result integrity | silent bad output | `package()` re-verifies the stored hash list against its root, every file against its sha256, and every playlist against the content-name rule before returning. Rendition alignment (identical segment durations, exactly 2 s) is enforced. |

## Sharp edges carried forward

- **ffmpeg itself parses untrusted media.** Run on uploads server-side (A2 `nfxd`
  ingest), it must be sandboxed (Kata / no network). The input pinning above closes
  protocol tricks, not decoder bugs.
- **CODECS reflects the stream, not the request.** x264's fastest presets emit
  Constrained Baseline. NFX-05 §1 now allows "High or a subset".
- `format_seconds` rounds exact binary ties to even where JS `toFixed` rounds them up
  (≤ 1 ms on a seek position). Documented in code.
