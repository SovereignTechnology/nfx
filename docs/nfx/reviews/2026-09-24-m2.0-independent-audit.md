# Independent audit: M2.0 contracts, mock and locked paths (`6caab27`, 2026-09-24)

- **Auditor:** a fresh agent with no author review to read.
- **Method:** `git archive 6caab27` into scratch, then:
  - mutant engines run against the suite;
  - parser probes;
  - lock bypasses tried in a throwaway clone.
- **Controls:** an honest re-implementation passed 14/14, and the runner caught the
  author's own planted flaws.
- **Verdict: not complete.**
  - **(a)** Ten plausibly wrong engines pass all 14 scenarios: eight seeders and two
    viewers.
  - **(b)** Two load-bearing spec claims are false: NFX-07 §3.4 "loss bounded by
    `window`", and NFX-10 §3.2 "exposure to aborted transfers bounded by `window`".
  - **(c)** The locked-path check can be bypassed with no diff in any locked path.
  - **(d)** The parser is strict apart from duplicate keys.

The resolutions are in the rework commit that follows. Each finding has a scenario or a
test there, and the mutants are kept as regression tests.

## Checked and found sound (auditor)

- **Numbers:** `1e3`, `17.0`, `-0`, `"17"`, `017`, `1E400`, 2^53 and above were all
  refused, and 2^53−1 accepted.
- **Limits:** the line and `detail` caps were correct at their boundaries.
- **Mock order:** the mock followed the §3 order and used `checked_mul`.
- **Planted flaws:** all 9 were caught.
- **Stubs:** doc comments only.
- **The lock failed closed on:** an edit, a new regular file, a removal, a rename, `chmod
  000`, a symlink replacing a pinned file or directory, and CRLF pins.
- **Purity:** `nfx-proto::pay` is pure.
- **Secrets:** no secrets in the diff.

## The rework, verified (author, before the second audit)

- **Suite:** 25 scenarios, run through `adversary_suite!`, pass against the honest mock.
- **Teeth:** 27 planted defects are each caught by the scenario written for them
  (`tests/mutants.rs`): the 19 seeder flaws (one of them against two scenarios) and 7
  viewer flaws. They include every mutant this audit ran.
- **Parser:** `pay1.json` holds 12 valid lines, 2 valid only with loopback allowed, and
  38 invalid lines. It passes natively and under `wasm32`, and every writer refuses what
  its reader would.
- **Lock:** each bypass was tried against the reworked check and refused:
  - `--pin` without unlocking;
  - unlocking under `CI`;
  - `#[path]` in `lib.rs`;
  - `include!` in an unguarded file;
  - a symlink in `engine/`, untracked and tracked;
  - a file name with a newline, untracked and tracked;
  - a scenario dropped from the suite;
  - a `build.rs`;
  - an edit to `check.sh`;
  - an edit to an engine stub.

  After each file was restored, the check read clean again.
- **CI:** `crates/ci/check.sh` passes in full.
