**The lock, re-scoped.** Three rounds running, the lock's bypasses attacked one claim: that
no crate anywhere compiles another crate's files. That claim was never the lock's job. The
money code is pinned file by file. A crate that compiles a pinned file changes nothing in
it, and money logic written afresh anywhere is a change no lock can tell from other code.
So the lock now guarantees, and checks:
- every pinned file, and what the money crates are built and tested with, is unchanged
  without a re-pin;
- every target of the two money crates shows what it compiled (a target without dep-info
  fails the check), and that it read only tracked files of its own crate;
- the money tests ran in full.

`check-locked.sh` states what it does not cover, and why.

The resolutions are in `64efd18` and `5ae9521`.

## The rework, verified (author, before the eighth audit)

- **Suite:** 62 scenarios pass against the honest mock (existing scenarios were extended;
  none dropped).
- **Teeth:** 174 planted defects are each caught. Each of the 20 new ones fails the
  assertion written for it.
- **Parser:** `window` 65 is refused and 64 accepted; the vectors regenerate, and the
  reference and Rust agree.
- **Lock:** every route still in scope was re-run and refused, with these outcomes:
  - The path crate outside the workspace is refused by `--sources` and `--facts`.
  - A run through plain `bash`, with an exported `env` function or `BASH_ENV`, is refused
    before anything else. Run directly, the same is refused by the environment check.
  - An nfx-proto test compiling an untracked file is refused.
  - An nfx-proto example compiling nfx-pay's file, named with `_` or with `-`, is refused.
    The first run of this attack exposed that `--all-targets` builds examples in test
    mode, and the rule had let every test-mode target read outside its crate. Only
    nfx-proto's integration tests may now (`5ae9521`).
  - The four smuggles into nfx-node are out of scope by the re-scope, and are no longer
    run.
- **CI:** `crates/ci/check.sh` passes in full.
