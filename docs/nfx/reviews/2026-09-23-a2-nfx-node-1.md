# Pre-push review — A2 `nfx-node` layer 1 (`a2/nfx-node`, 2026-09-23)

Scope:
- `crates/nfx-node`: store, node, seed, fetch, gossip, video, and the integration test;
- NFX-06 §2 (the `meta` collection now carries thumbs and subtitles);
- `deny.toml` for iroh's dependency tree;
- the status file.

Method: `differential-review` (network-facing code) and `sharp-edges`.

## Adversarial pass

| Attack | Result |
|---|---|
| A seeder serves bytes the hash list does not name | Every member is re-anchored to sha256 **by position** before anything is stored. Tested: a lying seeder whose BLAKE3 is self-consistent is caught at `720p member 2`, and nothing from that collection reaches the store. |
| Reordered or padded collection | Member counts must equal what the hash list and playlist imply, and members are compared position by position. |
| Forged hash list | The meta collection's first member must hash to the manifest `root`, then passes `HashList::verify` (video, segs, rendition rules). |
| Poisoned playlist steering what counts as a rendition | Playlists are content-name checked. Rendition membership is read from the verified playlist, and `EXT-X-MAP` must name exactly one listed init. |
| Path traversal via store names | `FsStore` accepts only 64-lowercase-hex names; anything else is an error. |
| Seeding bytes that rotted on disk | `seed` re-verifies every file against its name before importing it. Import by reference is safe because store files are content-addressed and never rewritten; any later change is caught by the receiver's re-anchor. |
| Forged or foreign gossip | Envelopes verify via `nfx-proto` (signature by the envelope's `pubkey`, clock skew, video must match the topic). Failures are counted and dropped, never surfaced. |
| Hung transfers | Each collection transfer has a 120 s timeout. |

## Sharp edges carried forward

- **The window gate (M2) is not in this layer.** `fetch` pulls whole collections, as a
  free (M1) peer does. Paid sessions need the per-member fetch of NFX-06 §2 and the
  seeder-side refusal; S1 proved the mechanism.
- **Iroh's FsStore referencing a store file** means deleting that file breaks seeding.
  The NFX store is append-only in M1; any garbage collection must untag in iroh first.
- **CI cost:** `nfx-node` puts iroh and, for tests, `iroh-relay`'s server into every
  pipeline on the shared runner. The first run compiles roughly 500
  crates; later runs use the cargo cache. Flagged to sovtech at push time.

## Supply chain

`cargo deny` is green with scoped changes:
- `CDLA-Permissive-2.0` (webpki root data) and `Unlicense` (public domain) are allowed;
- `MPL-2.0` is a per-crate exception for `attohttpc` (iroh > portmapper > igd-next);
- `RUSTSEC-2024-0436` (`paste`) and `RUSTSEC-2024-0370` (`proc-macro-error`), both
  unmaintained compile-time macros, are ignored with written reasons, to revisit at
  each iroh bump.

Verdict: **no blocker.** The push waits for sovtech's OK.
