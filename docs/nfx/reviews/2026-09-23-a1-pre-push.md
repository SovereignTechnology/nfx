## Sharp edges carried into the real implementation

- **The browser's sha256 needs a secure context** (S3). `crypto.subtle` is missing on
  plain `http://` except `localhost`, and a validator that throws there must fail
  closed. Prefer the `nfx-proto` WASM hash.
- **Payment gating on iroh must refuse bulk HashSeq requests from paying peers** (S1).
  Without that rule the window is bypassed in a single request.
- **p2p-media-loader destroys a peer on a failed validation**, which is good. Whether
  the peer can come back through the tracker later is untested. Local bans for M2
  belong in the fork (S3).

Verdict: **no blocker.** Both findings are fixed and re-tested (S3 4/4 after the fix).
Push is subject to sovtech's OK.
